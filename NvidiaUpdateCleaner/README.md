# NvidiaUpdateCleaner

A lightweight PowerShell module designed for system administrators and power users to audit, report, and clean up residual files left behind by NVIDIA Graphics Driver updates, GeForce Experience, and the NVIDIA App.

---

## Why Is Cleanup Needed?

NVIDIA installer tools and background update services leave significant residual data on your storage drive after updates complete:

1. **Extracted Setup Archives (`C:\NVIDIA\DisplayDriver`)**: When extracted manually or via setup wrappers, full uncompressed driver installer folders (~600 MB to 1 GB each) are left behind on the root drive.
2. **Installer Package Cache (`C:\Program Files\NVIDIA Corporation\Installer2`)**: The installer maintains cached package folders for past component installations. Over multiple driver updates, this directory can grow into several gigabytes.
3. **Downloader Cache & OTA Artifacts (`C:\ProgramData\NVIDIA Corporation\Downloader` & `NVIDIA app\UpdateFramework\ota-artifacts`)**: GeForce Experience and the new NVIDIA App store complete setup packages (`.exe`) and uncompressed OTA driver artifacts in hidden `ProgramData` directories (which can grow to **4+ GB**).
4. **Application Diagnostic Logs (`C:\ProgramData\NVIDIA Corporation\NVIDIA app\Logs`)**: Rotated container logs and setup trace logs generated by background services.
5. **Temporary Setup Files (`%TEMP%`)**: Driver setup leaves temporary extraction folders starting with `CUDA`, `NVIDIA`, `NV_`, or `NVI2_` in the user's temp directory.
6. **Shader Caches (`%LOCALAPPDATA%\NVIDIA\DXCache` & `GLCache`)**: Compiled DirectX and OpenGL shaders accumulate for older driver versions and uninstalled games.
7. **DLSS / NGX Model Cache (`C:\ProgramData\NVIDIA\NGX\models`)**: Downloaded DLSS model snapshots, typically 1+ GB. The driver re-downloads what it needs.
8. **Driver Store (`C:\Windows\System32\DriverStore\FileRepository`)**: Every driver update leaves the previous package behind. Display driver packages are **2 to 3 GB each**, so this is usually the largest NVIDIA leftover on the machine and the one no other cleanup tool touches. Windows never removes them on its own.

## Installation & Importing

To import the module into your current PowerShell session, navigate to the `admin-helpers` repository root and run:

```powershell
Import-Module .\NvidiaUpdateCleaner\NvidiaUpdateCleaner.psd1 -Force
```

To make the module permanently available across all PowerShell sessions, copy the `NvidiaUpdateCleaner` directory into one of your `$env:PSModulePath` locations (e.g. `$HOME\Documents\PowerShell\Modules`).

## Cmdlets & Usage Guide

### 1. `Get-NvidiaUpdateCleanupInfo` (Alias: `Get-NvidiaCleanupInfo`)

Audits known NVIDIA leftover paths and outputs a summary of leftover files, including category, path, file count, total size in MB, and a description.

```powershell
# Audit default installer leftover paths (Extracted setup, Installer2, Downloader cache, Logs, %TEMP%)
Get-NvidiaUpdateCleanupInfo

# Audit including DirectX and OpenGL shader caches (also includes the DLSS model cache)
Get-NvidiaUpdateCleanupInfo -IncludeShaderCache

# Audit everything, including superseded driver-store packages
Get-NvidiaUpdateCleanupInfo -IncludeShaderCache -IncludeDriverStore

# Filter by specific categories
Get-NvidiaUpdateCleanupInfo -Category DownloaderCache, ExtractedInstaller, ApplicationLogs
```

#### Output Example

```text
Category        Path                                                                          FileCount   SizeMB Description
--------        ----                                                                          ---------   ------ -----------
InstallerCache  C:\Program Files\NVIDIA Corporation\Installer2                                     1423   282.55 Cached package folders saved...
DownloaderCache C:\ProgramData\NVIDIA Corporation\Downloader                                          3     0.01 Downloaded driver setup packages...
DownloaderCache C:\ProgramData\NVIDIA Corporation\NVIDIA app\UpdateFramework\ota-artifacts             1282  4571.03 Over-The-Air (OTA) downloaded driver...
ApplicationLogs C:\ProgramData\NVIDIA Corporation\NVIDIA app\Logs                                      15   181.75 Rotated diagnostic log files...
```

### 2. `Remove-NvidiaUpdateCleanupItem` (Alias: `Remove-NvidiaCleanupItem`)

Safely deletes leftover files and folders to reclaim disk space. Fully supports pipelined objects from `Get-NvidiaUpdateCleanupInfo` and standard safety parameters (`-WhatIf` and `-Confirm`).

```powershell
# Dry-run preview of what would be removed
Get-NvidiaUpdateCleanupInfo | Remove-NvidiaUpdateCleanupItem -WhatIf

# Perform actual cleanup of installer leftovers
Get-NvidiaUpdateCleanupInfo | Remove-NvidiaUpdateCleanupItem

# Perform cleanup including shader caches (prompts for confirmation)
Remove-NvidiaUpdateCleanupItem -IncludeShaderCache

# Force removal of read-only items without interactive prompts
Get-NvidiaUpdateCleanupInfo | Remove-NvidiaUpdateCleanupItem -Force

# Full sweep including shader caches and superseded driver-store packages (elevated session)
Get-NvidiaUpdateCleanupInfo -IncludeShaderCache -IncludeDriverStore | Remove-NvidiaUpdateCleanupItem
```

---

### 3. `Get-NvidiaDriverStorePackage`

Lists every NVIDIA package in the Windows driver store with its version, date, on-disk size, and a status. Works without elevation.

| Status | Meaning | Removed by default? |
| :--- | :--- | :---: |
| **InUse** | A present device is bound to this package. | Never |
| **Superseded** | An older package of a family that also has a newer one. | Yes |
| **Unused** | Newest of its family, but no present device is bound to it. Usually an older driver generation (e.g. `nv_dispi.inf` after the GPU moved to `nvmdi.inf`) or hardware no longer connected. | Only with `-IncludeUnused` |

```powershell
# See everything, with sizes
Get-NvidiaDriverStorePackage | Format-Table PublishedName, OriginalName, DriverVersion, DriverDate, Status, SizeMB

# Just the removable ones
Get-NvidiaDriverStorePackage -Status Superseded, Unused
```

#### Output Example

```text
PublishedName OriginalName  DriverVersion  DriverDate Status     SizeMB
------------- ------------  -------------  ---------- ------     ------
oem142.inf    nvmdi.inf     32.0.16.1692   2026-09-04 InUse     2718.20
oem135.inf    nvmdi.inf     32.0.16.1047   2026-05-19 Superseded 2685.10
oem97.inf     nv_dispi.inf  32.0.15.7700   2025-07-14 Unused    2413.70
oem144.inf    nvhda.inf     1.4.6.3        2026-07-23 InUse        0.20
oem133.inf    nvhda.inf     1.4.5.7        2025-12-01 Superseded   0.20
```

---

### 4. `Remove-NvidiaDriverStorePackage`

Removes driver-store packages with `pnputil /delete-driver`. In-use packages are always skipped, and pnputil is called without `/force`, so Windows itself refuses anything still bound to a device. Requires an **elevated** session unless `-WhatIf` is used.

```powershell
# Preview
Get-NvidiaDriverStorePackage | Remove-NvidiaDriverStorePackage -WhatIf

# Remove superseded packages only
Remove-NvidiaDriverStorePackage

# Also remove Unused packages (review the list first)
Remove-NvidiaDriverStorePackage -IncludeUnused
```

## Safety & Permissions

- **Administrator Privileges**: Cleaning system-level paths (`C:\Program Files\NVIDIA Corporation\Installer2` and `C:\ProgramData\NVIDIA Corporation`) requires running PowerShell as an **Administrator**.
- **Dry-Run Mode (`-WhatIf`)**: Always recommended before performing deletions to review exact paths and sizes.
- **Shader Caches**: Clearing shader caches (`DXCache` / `GLCache`) is completely safe. Windows and GPU drivers will automatically re-compile shaders when games or applications are launched.
- **Driver Store**: Auditing is read-only and works unelevated. Removal uses `pnputil` without `/force`, so a package still bound to a device cannot be deleted even if misclassified. Removing a superseded package only means you can no longer roll back to that driver version from Device Manager; reinstalling from a downloaded package still works.

## Cleanup Categories Breakdown

| Category | Typical Location | Safe to Remove? | Description |
| :--- | :--- | :---: | :--- |
| **ExtractedInstaller** | `C:\NVIDIA\DisplayDriver` | Yes | Raw extracted installer files from manual setup. |
| **InstallerCache** | `C:\Program Files\NVIDIA Corporation\Installer2` | Yes | Backup installer packages maintained by NVIDIA setup. |
| **DownloaderCache** | `C:\ProgramData\...\Downloader`, `ota-artifacts` | Yes | Downloaded `.exe` setup files and OTA artifacts from GFE / NVIDIA App. |
| **ApplicationLogs** | `C:\ProgramData\NVIDIA Corporation\NVIDIA app\Logs` | Yes | Rotated service log files (`LOG.NVDisplay.Container.exe.log*`). |
| **TempInstallationFiles** | `%TEMP%\NVIDIA*`, `CUDA*`, `NV_*` | Yes | Scratch files created during setup execution. |
| **ShaderCache** | `%LOCALAPPDATA%\NVIDIA\DXCache` | Yes | Compiled DirectX/OpenGL shader files (rebuilt automatically). |
| **NgxModelCache** | `C:\ProgramData\NVIDIA\NGX\models` | Yes | DLSS model snapshots (re-downloaded on demand). Included with `-IncludeShaderCache`. |
| **DriverStore** | `C:\Windows\System32\DriverStore\FileRepository` | Yes (Superseded) | Previous driver packages no device is bound to. Included with `-IncludeDriverStore`; removed via `pnputil`. |
